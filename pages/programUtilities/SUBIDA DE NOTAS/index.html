Generador de script de notas

Pega tu Excel (con encabezados), elige las columnas y copia el script para la consola del sistema.

1. Pega aquí los datos del Excel

2. Columnas → campos del sistema

Marca las columnas que quieres cargar y a qué campo (.campoN) va cada una. Por defecto: las 5 primeras columnas de notas en .campo1 a .campo5 (como en tu script anterior; la Nota Final la calcula el sistema).

3. Script para la consola

En el sistema: abre la página con la lista de alumnos, presiona F12 → pestaña Consola, pega el script y Enter.
